# Журналирование

## Назначение

Журналирование используется для фиксации хода выполнения бизнес-операций, диагностики интеграционных ошибок и сопровождения работы модулей.

## Область применения

Журналирование обязательно для следующих операций:

- создание заявки на бронирование;
- проверка доступности аудитории;
- подтверждение заявки;
- резервирование временного слота;
- отмена бронирования;
- освобождение временного слота;
- обработка ошибок взаимодействия модулей.

## Контекстные поля

Каждая запись журнала должна содержать достаточный контекст для идентификации операции.

| Поле | Назначение |
| --- | --- |
| Timestamp | Время события |
| Level | Уровень журналирования: Information, Warning, Error |
| Module | Модуль, выполнивший операцию |
| Operation | Название операции |
| BookingId | Идентификатор заявки |
| ClassroomId | Идентификатор аудитории |
| SlotId | Идентификатор временного слота |
| UserId | Идентификатор пользователя |
| AdminId | Идентификатор администратора |
| StartTime | Начало временного интервала |
| EndTime | Конец временного интервала |
| Result | Результат операции |
| ErrorCode | Код ошибки, если операция завершилась неудачно |
| CorrelationId | Идентификатор сквозной операции |

## Уровни журналирования

| Уровень | Когда используется |
| --- | --- |
| Information | Успешное выполнение ключевых операций |
| Warning | Отказ в операции по бизнес-причине, например конфликт расписания |
| Error | Системная ошибка, исключение, нарушение контракта модулей |

## Правила безопасности

В журнал запрещено записывать:

- пароли;
- токены;
- закрытые ключи;
- строки подключения с секретами;
- персональные данные сверх минимально необходимых для диагностики.
