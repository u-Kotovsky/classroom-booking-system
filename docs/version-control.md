# Правила работы с Git

## Ветки

| Ветка | Назначение |
|-------|------------|
| `main` | Стабильная версия проекта |
| `develop` | Объединение результатов разработки |
| `feature/*` | Новые функции, напр. `feature/booking-creation` |
| `fix/*` | Исправления, напр. `fix/time-validation` |
| `docs/*` | Изменения документации, напр. `docs/project-artifacts` |

## Коммиты

Один коммит — одно логически завершённое изменение.

| Префикс | Назначение |
|---------|------------|
| `feat:` | Новая функциональность |
| `fix:` | Исправление |
| `docs:` | Документация |
| `test:` | Тесты |
| `refactor:` | Изменение структуры кода |
| `chore:` | Техническое изменение |

Запрещены малоинформативные сообщения: `update`, `fix`, `work`, `123`.

## Проверка

Перед началом этапа фиксируется `git status`.
После завершения этапа репозиторий не должен содержать незакоммиченных изменений.
